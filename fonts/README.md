# IBM Plex fonts

IBM Plex Sans and IBM Plex Serif variable fonts, including italic variants.
Distributed under the SIL Open Font License; see the adjacent license files.
Upstream: https://github.com/IBM/plex

The package names these fonts but never installs them. For CLI examples pass
`--font-path fonts`, or install the fonts through your operating system.
New Computer Modern and Serif are fallback families when Plex is unavailable.
